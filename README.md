# dm_open_ide README

dm_open_ide is a project by F0lak to create a community-made IDE to address shortcomings in BYOND's native IDE: Dream Maker.

The project aims to create a standalone program that implements modern niceties and functionality such as:
[ul]
* Dark Mode and custom UI theming
* Intellisense
* Real-time error detection
* Pre-compilation scanning
* Syntax Highlighting with more granularity
[/ul]
