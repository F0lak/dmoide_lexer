# dm_open_ide README

dm_open_ide is a project by F0lak to create a community-made IDE to address shortcomings in BYOND's native IDE: Dream Maker.

The project aims to create a standalone program that implements modern niceties and functionality such as:
* Dark Mode and custom UI theming
* Intellisense
* Real-time error detection
* Pre-compilation scanning
* Syntax Highlighting with more granularity

The initial goal of the project is to create a forward compiler that is on par with BYOND's compiler in regards to error detection, lexical analysis and logical parsing.
Future goals for the project include:
* DMI editor
* Map editor
* Expanded support for more languages, such as html, css, javascript, json, raw text files and BYOND's native .sav files
